# Goxcity 3D

A PS1-style true-3D fork of Go × City. Same city-building rules, seasons,
economy, boats, rail, civic growth, CPU mayor, and soundscape — rendered
through a perspective software-3D engine with extruded terrain meshes,
low-poly buildings, depth sorting, vertex snapping, and scanlines.

The playing field spins through a continuous 360° orbit (pausable).

Open `index.html` in a browser to play. Zero dependencies, zero build step.
